# BrandTwin Studio

Commercial CPG Packaging and Ad Creative Engine landing page.

Built with clean semantic HTML5, modern typography, Tailwind CSS, interactive before/after packaging transformation sliders, 3-card comparison, productized client workspace UI preview, and discovery call booking modal.

## Deploying on Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Keep the default settings (Static HTML).
3. Click **Deploy**.
